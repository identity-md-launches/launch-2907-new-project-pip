# Screenshot evidence · texture repair

Actual captures of the final production `dist/` on 2026-11-03. All are full-size viewport
screenshots, except the explicitly identified full-page restore check. JPEGs were optimized with
MozJPEG quality 66 after capture; no runtime artwork was changed. No physical-phone test is claimed.

`public-before.jpg` is the **actual public failure** at
https://pip-squeekchain-hamster-com-edf1.imd.site/ in Chromium, 1280×720: mesh present, grey material,
missing maps. It is not a screenshot of the repaired release.

The `chromium-*` and `webkit-*` captures come from `scripts/check-textures.mjs` using Playwright
1.58.2, fresh disposable contexts, device scale 1. Chromium 145.0.7632.6 uses SwiftShader; WebKit
26.0 uses Mesa software WebGL2. The exact complete export is served at `/preview/` with the actual
publication CSP. Optional external AI/RPC requests are blocked. These are **local repaired-export**
captures; repaired-public validation is pending publication.
