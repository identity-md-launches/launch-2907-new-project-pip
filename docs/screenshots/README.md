# Screenshot evidence

Actual Chromium 145 captures of the final production export, generated by
`SHOTS=docs/screenshots npm run e2e` on 2026-11-03 with Playwright 1.58.2, device scale 1 and
SwiftShader WebGL. Each context starts fresh. All off-origin network requests are blocked;
chain sources are unavailable and any event reaction is an explicitly simulated rehearsal.
These are viewport checks, not physical-device or real-inference results.
